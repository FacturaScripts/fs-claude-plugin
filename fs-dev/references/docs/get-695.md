El método `get()` busca un registro por su **clave primaria** y devuelve una **nueva instancia** del modelo con sus datos. Si el registro no existe, devuelve `false`.

&gt; **Recomendación:** en código nuevo usa `find()`. Hace lo mismo, no necesita instanciar el modelo y devuelve `null` en lugar de `false`, lo que permite tipar el resultado (`?Familia`).

## Uso básico

```php
use FacturaScripts\Dinamic\Model\Familia;

$familia = (new Familia())-&gt;get(&#39;1234&#39;);
if (false === $familia) {
    // la familia 1234 no existe
    return;
}

echo $familia-&gt;descripcion;
```

## Parámetros y valor devuelto

- **`$code`**: valor de la clave primaria del modelo (la columna que devuelve `primaryColumn()`). Puede ser `string` o `int` según el modelo. Si es `null`, devuelve `false` directamente.
- **Devuelve**: una instancia nueva del modelo (`static`) si el registro existe, o `false` si no existe.

Importante: `get()` **no modifica** el objeto sobre el que se llama. Ese objeto sigue vacío; los datos están en el objeto devuelto.

## get(), find() y load(): cuál usar

Los tres métodos buscan por clave primaria. Cambia lo que devuelven y dónde quedan los datos:

```php
use FacturaScripts\Dinamic\Model\Familia;

// get(): nueva instancia o false
$a = (new Familia())-&gt;get(&#39;1234&#39;);

// find(): nueva instancia o null, sin instanciar (recomendado)
$b = Familia::find(&#39;1234&#39;);

// load(): rellena el objeto actual y devuelve true/false
$c = new Familia();
if ($c-&gt;load(&#39;1234&#39;)) {
    echo $c-&gt;descripcion;
}
```

- Usa **`find()`** cuando solo necesitas obtener el registro. Es la opción recomendada.
- Usa **`load()`** cuando ya tienes un objeto (por ejemplo, `$this` dentro de un modelo o un objeto que te pasan) y quieres rellenarlo.
- **`get()`** está marcado como obsoleto (`@deprecated`) y solo se mantiene por compatibilidad con código anterior. No lo uses en código nuevo.

## Buscar por otros campos

Si no buscas por la clave primaria, usa `findWhere()`, `findWhereEq()`, `loadWhere()` o `loadWhereEq()`:

```php
use FacturaScripts\Core\Where;
use FacturaScripts\Dinamic\Model\Familia;

// primera familia con esa descripción
$familia = Familia::findWhere([Where::eq(&#39;descripcion&#39;, &#39;Tornillería&#39;)]);

// lo mismo, con un único campo
$familia = Familia::findWhereEq(&#39;descripcion&#39;, &#39;Tornillería&#39;);

// lo mismo, rellenando un objeto existente
$familia = new Familia();
$familia-&gt;loadWhereEq(&#39;descripcion&#39;, &#39;Tornillería&#39;);

// con varias condiciones y orden
$familia-&gt;loadWhere(
    [Where::like(&#39;descripcion&#39;, &#39;torn&#39;)],
    [&#39;codfamilia&#39; =&gt; &#39;ASC&#39;]
);
```

## Errores frecuentes

- **Comprobar con `null`**: `get()` devuelve `false`, no `null`. Una comprobación `if (null === $familia)` no detecta el caso de &quot;no existe&quot;. Con `find()` sí se compara con `null`.
- **Esperar que rellene el objeto**: `$modelo-&gt;get(&#39;1234&#39;)` no carga los datos en `$modelo`. Para eso está `load()`.
- **Perder datos con `load()` o `loadWhere()`**: si el registro no existe, estos métodos vacían el objeto (`clear()`) antes de devolver `false`. Si el objeto ya tenía datos, se pierden. La excepción es `load()` con un código `null` o vacío: devuelve `false` sin tocar el objeto. Comprueba siempre el valor devuelto.
- **Usarlo dentro de bucles**: llamar a `get()` o `find()` por cada elemento de una lista lanza una consulta por registro. Si necesitas muchos registros, cárgalos de una vez con `all()` y `Where::in()`:

```php
$familias = Familia::all([Where::in(&#39;codfamilia&#39;, $codigos)]);
```
