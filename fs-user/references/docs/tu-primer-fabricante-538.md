Puedes ver el listado de fabricantes desde el **menú Almacén → Fabricantes**.

## 🛠️ Crear un fabricante

Para crear un nuevo fabricante, accede al **menú Almacén → Fabricantes**, y haz clic en el **botón nuevo**. Completa los campos que se solicitan:

- **Código:** Ingresa un código único para el fabricante.
- **Nombre:** Proporciona el nombre del fabricante.

Si dejas el código en blanco, el programa genera uno automáticamente.

Una vez completados estos campos, puedes proceder a asignar el fabricante a un artículo o producto según sea necesario. En el listado de fabricantes verás una columna con el **número de productos** que tiene asignados cada uno.

## 🔍 Filtrar los productos por fabricante

Una vez asignados, en el **menú Almacén → Productos** tienes un filtro por fabricante. Es la utilidad principal de los fabricantes: acotar un catálogo grande.

La ficha del fabricante tiene además dos pestañas:

- **Productos:** los productos que ya tiene asignados.
- **Añadir:** el resto del catálogo, para asignarle productos **en bloque** sin tener que abrir uno a uno. Es lo práctico cuando das de alta un fabricante y ya tienes los productos creados.

Si no encuentras el filtro, o quieres que la columna del fabricante se vea en el listado, puedes ajustarlo con el [botón opciones](https://facturascripts.com/publicaciones/boton-opciones).

## ⚠️ Antes de eliminar un fabricante

Al borrar un fabricante **no se borran sus productos**: simplemente se quedan sin fabricante asignado. Si solo quieres reorganizar el catálogo, no hay riesgo de perder productos.

## ⚖️ Diferencias entre fabricantes y proveedores

Los fabricantes permiten agrupar o filtrar productos, mientras que los proveedores son entidades a las cuales se les compran productos. Además, un producto puede tener solo un fabricante, pero puede ser adquirido de múltiples proveedores.
