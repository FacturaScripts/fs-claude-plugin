## 📦 Cómo afectan las ventas al stock

Con los estados predeterminados, un presupuesto no modifica el stock, un pedido reserva unidades y un albarán o una factura resta existencias. Este comportamiento depende del campo **Actualizar stock** de cada estado y se puede configurar.

Consulta [el stock del producto](https://facturascripts.com/publicaciones/el-stock-de-productos) y [los estados del documento](https://facturascripts.com/publicaciones/estados-del-documento-680) para entenderlo en detalle.
