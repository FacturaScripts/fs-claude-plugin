RenombrarReferencia es un plugin que permite cambiar la referencia de un producto (o de una de sus variantes) de forma segura: la nueva referencia se actualiza automáticamente en el propio producto, en proveedores, tarifas, stock, imágenes y en las líneas de documentos que todavía estén abiertos/editables. Los documentos ya cerrados o facturados conservan la referencia original, por trazabilidad. Además, el plugin guarda constancia del cambio: la ficha del producto muestra la última referencia que tuvo antes de renombrarse, se registra un historial completo con fecha y usuario de cada cambio, y tanto el listado de productos como el buscador permiten trabajar con esa referencia antigua.
