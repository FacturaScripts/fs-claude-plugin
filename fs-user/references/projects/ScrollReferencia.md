Añade un scroll interno al desplegable de búsqueda de referencias en pedidos, presupuestos, albaranes y facturas (compras y ventas), evitando que el listado de artículos empuje el resto de la página. Útil cuando tenemos muchas referencias.
- El desplegable de sugerencias ya no crece sin límite: tiene una altura fija máxima con scroll propio.
- Si el campo está cerca del final de la página, el desplegable se abre hacia arriba automáticamente en vez de quedar cortado.
- La rueda del ratón mueve siempre el listado de sugerencias, nunca la página, esté el cursor donde esté mientras el desplegable está abierto.
- El primer resultado queda resaltado al abrirse, para poder navegar con el teclado o confirmar con Intro si queremos no usar el ratón.  Con el ratón podemos manejar el listado con la rueda de scroll y elegir con el botón este.
- Contiene una barra deslizante lateral

SI EL PLUGIN ES DE UTILIDAD VÓTALO PULSANDO EN LOS CORAZONES. SI NO PUEDE PASAR  QUE SE RETIRE. GRACIAS.
