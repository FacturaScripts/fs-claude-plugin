Comparte tus documentos de FacturaScripts en un clic.
Click2Share te permite compartir documentos de FacturaScripts de forma rápida y directa desde el propio menú de impresión. Genera el PDF nativo de facturas, presupuestos, pedidos, albaranes y listados, y compártelo mediante WhatsApp, Telegram, email, AirDrop, Teams o cualquier aplicación compatible con tu dispositivo. Sin API de Meta, sin tokens, sin configuraciones externas y sin alterar el formato PDF de FacturaScripts.

Imprimir → Compartir → elegir aplicación
