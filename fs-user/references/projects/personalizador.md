ThemeCustomizer agrega una seccion llamada Estilos dentro del panel de configuracion de FacturaScripts. Desde esa pantalla se pueden modificar colores del header, menu lateral, submenus, enlaces, botones, fondos, titulos, textos informativos y pantalla de login sin editar plantillas manualmente.

El plugin inyecta CSS en la plantilla principal de FacturaScripts usando una extension de vista, por lo que mantiene los cambios separados del nucleo de la aplicación.

https://github.com/mdamplus/facturaScriptsThemeCustomizer
