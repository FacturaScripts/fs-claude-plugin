Plugin para FacturaScripts que calcula y mantiene los plazos reales de entrega a partir de documentos de compra, permitiendo analizar el rendimiento de proveedores de forma objetiva y basada en datos reales.

El plugin mide el tiempo transcurrido entre la fecha del pedido y la fecha de recepción de la mercancía, almacenando esta información para su posterior consulta y análisis.

Funcionalidades principales
----------------------------
El plugin detecta las líneas de albarán que provienen de un pedido de proveedor. 
Calcula automáticamente el tiempo de entrega para cada línea.
Consolida la información por producto y proveedor, manteniendo:
- el plazo de entrega del último suministro
- el plazo medio de entrega histórico

Como resultado permite:
- Comparar proveedores por rapidez de suministro.
- Detectar retrasos recurrentes en determinados productos.
- Mejorar decisiones de compra basadas en datos históricos reales.
- Evaluar el rendimiento logístico de proveedores.
