ProyectosArq es la extensión del plugin Proyectos adaptada a estudios de arquitectura. Organiza cada encargo por fases, planifica los plazos y controla el avance del estudio dentro de FacturaScripts 2026.

## Funciones principales

- **Kanban por fases:** tablero con las fases del estudio (anteproyecto, proyecto básico, proyecto de ejecución y dirección de obra); arrastra las tareas entre columnas.
- **Diagrama de Gantt:** planifica los plazos de cada tarea y visualiza el calendario completo del proyecto.
- **Dependencias entre tareas:** define qué tareas dependen de otras para controlar el orden de ejecución.
- **Panel de control:** estado y avance de cada proyecto de un vistazo.
- **Participantes:** asignación de responsables a las tareas y a cada proyecto.
- **Notificaciones internas:** avisos automáticos al equipo cuando cambian las tareas.
- **Auditoría:** histórico de estados de cada tarea y proyecto.
