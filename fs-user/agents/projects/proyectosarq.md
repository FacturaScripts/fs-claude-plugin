Extensión del plugin Proyectos especialmente adaptada a estudios de arquitectura. Organiza las tareas de cada proyecto en un tablero Kanban por fases (anteproyecto, proyecto básico, proyecto de ejecución y dirección de obra) que se arrastran entre columnas, planifica los plazos con un diagrama de Gantt y define dependencias entre tareas para controlar el orden de ejecución. Incluye un panel de control con el estado y el avance de cada proyecto, asignación de participantes, notificaciones internas cuando cambian las tareas y auditoría del histórico de estados. Ejemplo de uso: un estudio crea el proyecto «Vivienda unifamiliar», añade las tareas de cada fase, indica que la «Dirección de obra» depende de finalizar el «Proyecto de ejecución» y sigue el avance global desde el panel mientras el equipo recibe avisos de cada cambio. Requiere el plugin Proyectos.
