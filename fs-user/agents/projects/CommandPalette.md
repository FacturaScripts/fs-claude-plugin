CommandPalette añade una paleta de comandos moderna a tu FacturaScripts, inspirada en herramientas como VS Code, GitHub y Cloudflare. Pulsa Ctrl+K (o Cmd+K en Mac) para
  abrir un buscador rápido que te permite navegar instantáneamente a cualquier sección del menú, crear nuevos registros y acceder a la configuración sin usar el ratón.

  Características principales:

  - Búsqueda difusa inteligente: Encuentra elementos del menú, páginas y acciones escribiendo solo unas letras
  - Creación rápida: Genera automáticamente comandos &quot;Nuevo Producto&quot;, &quot;Nuevo Cliente&quot;, etc. desde los controladores List
  - Atajos de teclado: Alt+N para crear un nuevo registro desde cualquier listado, Alt+S para guardar
  - Navegación completa con teclado: Flechas arriba/abajo, Enter para seleccionar, Escape para cerrar
  - Botón en la barra de navegación: Acceso visual para quienes prefieren el ratón
  - Multiidioma: Soporte completo para español, inglés y otros idiomas
  - Accesibilidad: Compatible con lectores de pantalla (ARIA)

  Mejora tu productividad navegando por FacturaScripts de forma más rápida y eficiente, ideal para usuarios que prefieren el teclado sobre el ratón.
