PdfFileNamer permite personalizar el nombre de los archivos PDF que genera FacturaScripts para cada tipo de documento. El administrador define un patrón con tokens como {company}, {code}, {customer}, {date} o {serie} desde el panel de configuración, y el plugin aplica ese nombre tanto en las descargas como en los envíos por email. Se pueden configurar patrones diferentes para facturas de cliente, facturas de proveedor, presupuestos, pedidos y albaranes.

Si no se define un patrón para un tipo de documento, el comportamiento por defecto de FacturaScripts no se altera.
