TicketsPOS es un plugin para FacturaScripts que conecta el módulo POS con el plugin Tickets, permitiendo que el punto de venta genere, envíe e imprima tickets personalizados mediante el motor de impresión del plugin Tickets.

Con esta integración, el POS puede aprovechar funciones del plugin Tickets.
