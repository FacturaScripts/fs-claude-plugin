Backup Auto permite crear copias de seguridad programadas, tanto de la base de datos como los archivos.

Tiene dos modos de funcionamiento, estándar y bajo consumo, al cual se puede asignar que cantidad de recursos usar del servidor, para que se haga la copia sin sobrecargar el sistema.

Las copias de seguridad se pueden programar por periodo, diario, semanal y mensual. Además se pueden comprimir en tar.gz, lo cuál permite ahorrar espacio.

Dispone de un visor de la tarea, mostrando el tiempo restante y tiempo transcurrido. 
También tiene una pequeña configuración de log propio, el cual permite detectar errores, procesos, y consultar las ultimas configuraciones.
