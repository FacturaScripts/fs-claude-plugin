Complemento del plugin Anticipos:
	- Requiere que el Plugin PlantillasPDF esté instalado y activado.
	- Da soporte para incluir el detalle de los anticipos recibidos, al generar el PDF del documento de Venta, mediante el Plugin PlantillasPDF.
	- Utiliza sólo la plantilla &quot;Template1&quot;, aunque se podría ampliar a otras plantillas.
	- Desde la versión 3.01 se puede seleccionar si se incluye la relación de anticipos en el documento que se está editando. El selector está en el modal del documento (el botón Detalle).
