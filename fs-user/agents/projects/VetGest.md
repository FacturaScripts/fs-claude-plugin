VetGest es un software completo para clínicas y consultas veterinarias integrado en FacturaScripts 2026. Pacientes (mascotas), propietarios, consultas, vacunaciones, cirugías y facturación en un mismo sistema.

## Funciones principales

- **Ficha de mascota:** especie, raza, microchip, alergias y foto.
- **Historia clínica:** consultas, diagnósticos y tratamientos.
- **Vacunaciones y desparasitaciones:** calendario con avisos.
- **Hospitalizaciones:** con control de estancias.
- **Recetas veterinarias:** y control de medicación.
- **Cirugías:** preparación, anestesia y seguimiento.
- **Facturación integrada:** en FacturaScripts a partir de consultas y servicios.
