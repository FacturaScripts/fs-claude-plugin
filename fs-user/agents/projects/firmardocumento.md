Permite firmar digitalmente albaranes, pedidos, facturas y presupuestos de cliente desde la pestaña firmas de cada documento.

Al firmar un documento se guardará:
- Imagen en formato PNG.
- Nombre y NIF del firmante (opcional).
- Ubicación en el mapa (opcional).
- Hora y fecha.

Permite enviar un enlace para firmar el documento por email o WhatsApp.

Este plugin no requiere configuraciones previas para la instalación, aunque es recomendable visitar el panel de control para personalizarlo.
