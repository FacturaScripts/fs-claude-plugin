📝 Descripción (repositorio FacturaScripts)

Copia de Seguridad Segura es un plugin para FacturaScripts que permite realizar copias de seguridad de la información de la aplicación y almacenarlas de forma cifrada en la nube de Iberbox, cumpliendo con las principales normativas de protección de datos.

El plugin requiere disponer de una cuenta activa en Iberbox, ya que las copias se envían automáticamente a dicha plataforma, donde se almacenan utilizando cifrado fuerte y control de acceso, evitando accesos no autorizados y pérdidas de información.

Está orientado a entornos donde la seguridad y el cumplimiento normativo son críticos, como empresas, gestorías y despachos profesionales.

Funcionalidades principales:

Creación de copias de seguridad de FacturaScripts.

Envío automático de las copias a Iberbox.

Almacenamiento cifrado de los backups en la nube.

Protección frente a accesos no autorizados.

Cumplimiento con normativas de protección de datos (RGPD).

Gestión sencilla desde el panel de administración de FacturaScripts.

El plugin está diseñado para ofrecer una solución de backup externo, seguro y conforme a normativa, minimizando riesgos ante fallos técnicos, errores humanos o incidentes de seguridad.

ℹ️ Requisitos

Cuenta activa en Iberbox.

Conexión a internet para el envío de las copias.

Instalación estándar de FacturaScripts.
