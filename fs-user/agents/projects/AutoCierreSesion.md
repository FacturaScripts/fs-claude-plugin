Plugin para FacturaScripts que cierra automáticamente la sesión del usuario tras un periodo de inactividad configurable desde el panel de control. 

Utiliza eventos del navegador para detectar actividad en tiempo real y sincroniza el cierre de sesión entre todas las pestañas abiertas simultáneamente, garantizando que ninguna sesión quede abierta por descuido.
