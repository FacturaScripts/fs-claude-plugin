El plugin CodigoAlternativo amplía el sistema de identificación de productos en FacturaScripts permitiendo trabajar con **códigos adicionales** distintos a la referencia interna y al código de barras.
Está diseñado para entornos donde un mismo producto puede tener múltiples códigos asociados, como referencias de proveedor, códigos internos alternativos, códigos de cliente o sistemas externos de inventario.

- Permite asociar múltiples códigos alternativos a un mismo producto.
- Posibilita la búsqueda de productos por:
    - Referencia
    - Código de barras
    - Códigos alternativos configurados
- Permite la **introducción rápida de líneas** en:
    - Documentos de venta
    - Documentos de compra
    - TPVNeo
- Mejora la agilidad en entornos con lectores de códigos o múltiples referencias operativas.
- Totalmente integrado con el flujo estándar de introducción de líneas de FacturaScripts.

Este plugin es especialmente útil para empresas que:
- Trabajan con varias referencias por producto.
- Utilizan códigos propios distintos al código de barras.
- Necesitan agilizar el proceso de venta en TPV.
- Gestionan referencias cruzadas con proveedores o clientes.
