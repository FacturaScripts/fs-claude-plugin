Plugin para FacturaScripts que mejora la experiencia de administración de productos cuando estos no utilizan combinaciones o variantes adicionales.

En FacturaScripts, todo producto dispone al menos de una variante obligatoria, asociada a su referencia principal. Aunque el producto no tenga tallas, colores u otras combinaciones, la estructura estándar obliga a gestionar sus datos, como precio de coste, precio de venta, código de barras, stock, etc., desde la pestaña **Variantes**.

Este plugin simplifica ese comportamiento cuando el producto solo tiene la variante obligatoria mostrando directamente en la pestaña principal del producto los campos de precio, stock, código de barras, etc.
