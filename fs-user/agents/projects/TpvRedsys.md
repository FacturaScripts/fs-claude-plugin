Pasarela Redsys + Bizum con Pago por Enlace

Este plugin integra la pasarela de pago Redsys en FacturaScripts, permitiendo aceptar pagos mediante tarjeta bancaria y Bizum de forma rápida, segura y totalmente compatible con los estándares actuales (SHA-256).

Además incorpora un sistema de enlace público de pago, ideal para cobrar a clientes sin necesidad de acceso al área privada. Desde el propio documento (factura, presupuesto, pedido, albarán…) podrás generar un link único y seguro que el cliente podrá abrir desde su móvil o cualquier navegador para completar el pago en la pasarela oficial de Redsys/Bizum.

Funciones principales
✔ Integración completa con Redsys (SHA-256).
✔ Compatibilidad con Bizum a través de Redsys.
✔ Generación de enlaces públicos de pago para enviar por email, WhatsApp o cualquier medio.
✔ Página de pago limpia y responsive para clientes.
✔ Validación automática del pago mediante notificación (callback) de Redsys.
✔ Actualización del estado del documento al pagarse.
✔ Registro de transacciones, códigos de respuesta y trazabilidad completa.
✔ Configuración sencilla: número de comercio, terminal, clave secreta y entorno (producción / pruebas).
✔ Multiidioma, traducciones realizadas al Español, Inglés y Catalán.

Ventajas
💳 Facilita el cobro de facturas, pedidos o presupuestos.
📲 Permite cobrar fácilmente mediante Bizum, (es necesario contratarlo con tu banco)
🔗 No requiere acceso de cliente: solo enviar un enlace.
🔒 Cumple con los estándares PSD2 y la seguridad de Redsys.
⚡ Reduce errores y acelera la gestión de cobros.

Limitaciones
Este plugin requiere un hosting y un dominio funcionando para poder trabajar, por lo que no es compatible con instalaciones de FacturaScripts en *localhost* o en un ordenador personal.
