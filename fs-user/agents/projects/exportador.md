El Plugin Exportador permite generar listados en formato XLS con información de clientes, proveedores y facturas, facilitando el análisis, control y tratamiento externo de los datos registrados en FacturaScripts.

Con este plugin podrás exportar de forma sencilla la información actual de clientes y proveedores, incluyendo datos como cuenta contable, NIF, nombre, razón social, teléfonos, email, dirección, forma de pago, IBAN, régimen de IVA y retención.

También permite exportar facturas emitidas y recibidas dentro de un rango de fechas, con posibilidad de filtrar por serie de facturación. El listado se genera con una línea por factura y separa las bases de impuestos en columnas independientes para cada tipo de impuesto configurado en FacturaScripts, incluyendo base, porcentaje, cuota y recargo de equivalencia.

Además, incorpora una función de control de facturas traspasadas, que permite bloquear las facturas ya exportadas para evitar que vuelvan a incluirse en futuras exportaciones cuando esta opción esté activa.
