Plugin diseñado para gestionar empleados, información laboral, asistencia, vacaciones, ausencias, documentos, anticipos y conceptos salariales desde una sola plataforma.
Permite centralizar la información del personal, controlar turnos y horas trabajadas, consultar vacaciones y documentos, y generar asientos contables para conceptos salariales configurados.
