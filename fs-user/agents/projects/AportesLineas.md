Control de Aportes de compra (Costes) para cada una de las lineas de venta. En cada línea de venta puedes vincular cantidad y precio de las compras realizadas. El plugin utiliza las líneas de los pedidos de venta para vincularles líneas de facturas de compra.
Para registrar un aporte (coste), debes editar el pedido de venta al cual quieras vincular los costes provenientes de una factura de compra. Verás que se muestra una nueva pestaña denominada "Líneas". En esa pestaña se mostrarán todas las líneas del pedido excepto las que tengan la cantidad a cero.
