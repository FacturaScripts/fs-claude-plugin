IntercompanyFS es un plugin de FacturaScripts diseñado para generar automáticamente Albaranes de Compra en la instalación de destino al vender a un cliente intercompany. Extiende el controlador EditAlbaranCliente, ofreciendo un botón para generar el documento remoto o visualizar el Albarán Destino ya asociado.
