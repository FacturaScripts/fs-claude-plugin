IntercompanyFS es un plugin de FacturaScripts diseñado para generar automáticamente Albaranes de Compra en la instalación de destino al vender a un cliente intercompany. Genera el albarán de compra en otra instalación de Facturascripts. Útil para quien maneja varias instalaciones de varias empresas que mantienen relaciones comerciales entre ellas. Extiende el controlador EditAlbaranCliente, ofreciendo un botón para generar el documento remoto o visualizar el Albarán Destino ya asociado.
