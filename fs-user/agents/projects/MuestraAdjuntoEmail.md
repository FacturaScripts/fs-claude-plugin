Muestra en el cuadro de diálogo de Email  los nombres de los archivos adjuntos pdf como enlaces clicables, links, para poder previsualizar o guardar estos antes de enviarlos.
No es necesario otro plugin, funciona sobre el cuadro de diálogo IMPRIMIR - EMAIL del core de Facturascripts, pero es compatible con Template1_ext.

Modo de Uso: Por ejemplo en una FACTURA.
Botón IMPRIMIR - Seleccionamos EMAIL, ahora Facturascripts generará la factura en PDF según el formato de impresión que tengamos configurado o el que esté por defecto. Mostrará el cuadro de diálogo del EMAIL y allí se verá el nombre del archivo que se va a adjuntar, en este caso una Factura. 
Antes de este plugin no había forma de saber el contenido del documento adjunto ya que no se daba acceso al documento. Ahora el Nombre del archivo adjunto se transformará en un enlace clickable o link para poder previsualizar y o incluso guardar el documento antes de darle al botón ENVIAR del cuadro de diálogo Email. 

Muy útil cuando tenemos muchos formatos de Impresión o cambiamos con frecuencia estos y no sabemos cual es el asignado en ese momento al documento que se va a enviar, o Incluso si utilizamos el plugin para PlantillasPDF llamado Template1_ext . 

Recordad que este plugin opcional Template1_ext permite asignar formatos de Impresión y configuraciones diferentes para cada Cliente, con lo que antes de ENVIAR el email con el adjunto, podemos abrir y ver este documento pdf y o guardarlo, o cancelar el envío.

Si pulsamos sobre el nombre del adjunto se abrirá el pdf.
