Plugin que permite ocultar los números, textos, fechas o importes para que no sean visibles si no se mueve el ratón durante x segundos, o si se activa el botón de ocultar, para evitar que si se deja el ordenador con el monitor encendido a los x segundos se pueda ocultar datos sensibles hasta que se vuelva a mover o se desmarque la opción de ocultar datos.
