Para actualizar los plugins de pago necesitas primero **registrar la instalación**, en caso contrario te saldrá un mensaje de `download-error` o `Código 401 - SUBSCRIPTION-NOT-FOUND` al intentar actualizar el plugin.

## ®️ Registrar instalación
Para registrar la instalación pulsa el **botón registrar** instalación en el actualizador. Ten en cuenta que deberás iniciar sesión en facturascripts.com para poder registrar la instalación.

![registrar instalacion](https://i.imgur.com/rRCNqxo.png)

Una vez registrada la instalación, solamente falta vincular la suscripción del plugin pulsando el **botón vincular**.

![vincular plugin de pago](https://i.imgur.com/CUQcvXN.png)

Tras vincular el plugin, ya puedes actualizarlo sin problemas desde el actualizador. Ten en cuenta que cuando compras un plugin, además del plugin, obtiene soporte de actualizaciones durante X meses. Cuando este soporte caduque recibirás un email informándote de los pasos a seguir.
