Cada producto en FacturaScripts tiene al menos una variante, y los precios se asignan a través de estas variantes. Para modificar el precio de un producto, sigue estos pasos:

1. Abre el producto en cuestión.
2. Haz clic en la **sección de variantes**.
3. Modifica el campo de precio según lo necesites.

![Modificar el precio del producto](https://facturascripts.com/MyFiles/2025/01/2591.png?myft=d62432737d048e5aece915eeebb08f56a0558531)

Los precios de los productos se muestran **sin impuestos** y en la [divisa predeterminada](https://facturascripts.com/publicaciones/divisas-773). Por ejemplo, si has seleccionado **euros**, todos los precios estarán en euros.

## Precio de coste

Puedes ver y modificar el precio de coste del producto desde la sección de variantes. Tienes dos opciones:
- Modificar el precio de coste de manera manual.
- Configurar que se calcule automáticamente.

Para habilitar el cálculo automático del precio de coste con cada compra, establece una [política de precios de coste](https://facturascripts.com/publicaciones/politicas-de-precios-de-coste) desde el **panel de control**.

## Margen

Es posible establecer un margen de beneficio en los productos, lo que permite calcular el precio de venta a partir del precio de coste siguiendo estas directrices:
- Si estableces un margen distinto de cero, el precio de venta se calculará aplicando ese margen al precio de coste.
- Si el margen es cero, el precio no se calculará automáticamente.

![Modificar margen del producto](https://facturascripts.com/MyFiles/2025/01/2593.png?myft=1fa53fd7720150f802b26aabd433045c57dec0a8)

Por ejemplo, si un producto tiene un precio de coste de 5€ y un margen del 100%, el precio de venta será de 10€.

Además, puedes establecer los precios de venta a partir del coste [utilizando las tarifas](https://facturascripts.com/publicaciones/las-tarifas-de-precios-por-clientes-o-grupos).
