Para cancelar una factura o realizar una rectificación o devolución, sigue estos pasos:

1. Abre la factura que quieres modificar.
2. Dirígete a la pestaña `Devoluciones`. Allí podrás indicar las cantidades a devolver de cada línea.
3. Una vez introducidas las cantidades, podrás generar la factura rectificativa.
4. También puedes elegir el estado en el que se creará la factura rectificativa.

![Pestaña Devoluciones de una factura de cliente con las cantidades a devolver por línea](https://i.imgur.com/W6NHrvd.png)

## 💶 Las devoluciones son por cantidad

Por ahora las devoluciones se calculan por cantidad, no por importe. Si quieres devolver un importe concreto, calcula la cantidad equivalente a partir del precio de la línea. Por ejemplo, si una línea tiene un precio de 10 € por unidad y quieres devolver 25 €, indica `2,5` como cantidad a devolver.

## 📋 Ver todas las rectificativas

Puedes consultar todas las facturas rectificativas desde el menú Ventas → Facturas, en la pestaña `Devoluciones`. Ese listado muestra únicamente las rectificativas y puedes buscarlas por código o filtrarlas por fecha.

## ⚠️ No se puede rectificar una rectificativa

Una factura rectificativa no puede, a su vez, rectificarse. Cuando abres una factura que ya es una rectificativa, la pestaña `Devoluciones` no está disponible. Si detectas un error en una rectificativa, corrígelo emitiendo una nueva rectificativa sobre la factura original.
