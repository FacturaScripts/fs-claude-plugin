Si necesita unir varios albaranes de un mismo cliente en una sola factura, puede hacerlo con el [asistente para agrupar o partir albaranes](https://facturascripts.com/publicaciones/el-asistente-para-agrupar-o-partir-documentos). Para ello vaya al **menú ventas, albaranes**, seleccione los albaranes que quiere unir y pulse el **botón agrupar**.

![agrupar albaranes](https://i.imgur.com/zMndp7a.png)

Los albaranes deben ser del mismo cliente y también del mismo almacén y serie, si no, no podrá unirlos.

![facturar albaranes cliente](https://i.imgur.com/dKhdWWr.png)![facturar albaranes cliente](https://i.imgur.com/dKhdWWr.png)

El asistente le mostrará el detalle de los albaranes y le permitirá seleccionar una nueva fecha para la factura. También puede **modificar las líneas y cantidades a seleccionar**, ya que esta herramienta permite también partir albaranes o agruparlos parcialmente.

Una vez seleccionada la fecha pulse el **botón generar** y seleccione facturar. Se facturarán todos los albaranes seleccionados en una sola factura.

![agrupar en factura](https://i.imgur.com/VwIc3uu.png)

Si desea facturar solamente una parte del albarán, rellene la columna **cant. seleccionada** con la cantidad que desea facturar de esa línea. En la columna servido puede ver si ya se ha facturado una parte de esa línea del albarán.
