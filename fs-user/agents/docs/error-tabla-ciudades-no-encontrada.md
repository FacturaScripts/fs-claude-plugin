Si después de actualizar FacturaScripts aparece el error de que la tabla de ciudades no se encuentra, puedes solucionarlo siguiendo estos pasos:

1. Haz clic en el **menú Administrador** → **Países**.
2. Al abrir el listado de países, se mostrarán las provincias y ciudades correspondientes, lo que forzará a FacturaScripts a generarlas si aún no existían.

Si el error persiste, puedes intentar pulsar el **botón Reconstruir** desde el menú **Administrador** → **Plugins**. Después, vuelve a consultar el listado de países para verificar si el problema se ha solucionado.
